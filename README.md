# DrowsyAlert

A CNN-based Driver Drowsiness Detection System.

## Requirements

- Python >= 3.12
- uv
- NVIDIA GPU + compatible driver (recommended)

## Installation

### 1. Clone repository

```powershell
git clone <repository-url>
cd drowsyalert
```

### 2. Install dependencies

```powershell
uv sync
```

### 3. run the application

```powershell
uv run python main.py
```
